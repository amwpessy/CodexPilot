## English

CodexPilot is a local macOS utility designed for Mac users who run Codex. It helps display Codex quota signals, Mac system status, disk read/write activity, disk growth, and local cache estimates on your own Mac.

### Data We Access

CodexPilot may read the following information locally on your Mac:

- Mac system status, such as CPU usage, memory usage, battery status, disk capacity, and disk read/write counters.
- Local Codex session log files, when available, to display quota-related information such as remaining quota and reset time if those fields are present in local Codex events.
- Local disk activity counters to help you understand frequent read/write behavior while Codex and other developer tools are running.
- Local user cache directories to estimate cache size and help clean common cache locations.
- Local monitoring history generated by CodexPilot to calculate since-launch disk, cache, and disk I/O changes.

### Data Collection

CodexPilot does not collect, transmit, sell, or share your personal data.

CodexPilot does not upload your Codex logs, quota events, system metrics, disk I/O metrics, cache paths, or usage information to any server.

### Tracking and Analytics

CodexPilot does not track you across apps or websites.

CodexPilot does not include advertising SDKs or analytics SDKs.

### Data Storage

CodexPilot may store local monitoring history on your Mac to calculate disk growth, disk read/write activity, and cache changes. This data remains on your device.

### Cache Cleaning

If you use the cache cleaning feature, CodexPilot removes files from configured local cache locations that are accessible to the app. This action happens locally on your Mac.

Before using cache cleaning, you should review the cache information shown in the app. Cache cleaning may remove temporary files that apps can recreate later.

### Codex Quota Information

CodexPilot reads quota-related signals only from local Codex session logs when those events are available. If your installed Codex version does not write quota information to local logs, CodexPilot may show quota as not reported.

### Third Parties

CodexPilot is an independent utility and is not affiliated with OpenAI. CodexPilot does not provide or resell Codex service access.

## 简体中文

Codex 驾驶舱是一款专门为在 Mac 上运行 Codex 的用户设计的本地 macOS 工具。它用于在你的 Mac 上显示 Codex 额度信号、Mac 系统状态、硬盘读写活动、硬盘增长和本地缓存估算。

### 我们访问的信息

Codex 驾驶舱可能会在你的 Mac 本地读取以下信息：

- Mac 系统状态，例如 CPU 使用率、内存使用率、电池状态、硬盘容量和硬盘读写计数。
- 本地 Codex session 日志文件；当日志中存在额度事件时，用于显示剩余额度、重置时间等信息。
- 本地硬盘活动计数器，用于帮助你了解 Codex 和其他开发工具运行时的频繁读写行为。
- 本地用户缓存目录，用于估算缓存大小，并帮助清理常见缓存位置。
- Codex 驾驶舱在本机生成的本地监控历史，用于计算从打开软件开始的硬盘、缓存和硬盘读写变化。

### 数据收集

Codex 驾驶舱不会收集、上传、出售或共享你的个人数据。

Codex 驾驶舱不会将你的 Codex 日志、额度事件、系统指标、硬盘读写指标、缓存路径或使用信息上传到任何服务器。

### 跟踪与分析

Codex 驾驶舱不会跨 App 或网站跟踪你。

Codex 驾驶舱不包含广告 SDK 或分析 SDK。

### 数据存储

Codex 驾驶舱可能会在你的 Mac 本地保存监控历史，用于计算硬盘增长、硬盘读写活动和缓存变化。这些数据仅保留在你的设备上。

### 缓存清理

如果你使用缓存清理功能，Codex 驾驶舱会从应用可访问的本地缓存位置删除文件。该操作仅在你的 Mac 本地执行。

使用缓存清理前，你应查看应用中显示的缓存信息。缓存清理可能会删除应用之后可重新生成的临时文件。

### Codex 额度信息

Codex 驾驶舱仅在本地 Codex session 日志存在额度事件时读取额度相关信号。如果你安装的 Codex 版本没有将额度信息写入本地日志，Codex 驾驶舱可能会显示额度未报告。

### 第三方关系

Codex 驾驶舱是一款独立工具，与 OpenAI 无隶属关系。Codex 驾驶舱不提供或转售 Codex 服务访问权限。
